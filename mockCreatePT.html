Badge Scan Security Analysis

Scenario: Physical Security Monitoring

ASCTE uses badge scanning to monitor building access across campus. Your task is to analyze badge scan records to identify patterns and support security investigations. The security team needs tools to quickly filter and analyze scan data by role type.

Official Create PT Instructions: AP CSP Student Task Directions

Understanding the Data

Each badge scan is recorded as a string containing three pieces of information separated by commas:

"F12345,08:30,Academic"
"S54321,14:15,Residential"
"G99887,09:00,Sentinel"

Data Components

  • Badge ID: First character indicates role (F=Faculty, S=Student, G=Guest), followed by 5-digit number
  • Time: 24-hour format (HH:MM)
  • Building: Academic, Residential, or Sentinel

Example: "F12345,08:30,Academic" means Faculty member with badge F12345 scanned into the Academic building at 8:30 AM

Your Task

Write a Python program that analyzes badge scan data. Your program will be provided with a pre-loaded list of scan records.

Base Requirements

Your program must include ALL of the following:

  • Prompt the user to input a role letter (F, S, or G)
  • Create a procedure that takes the role letter as a parameter
  • Your procedure must find and display all scan records that match the specified role
  • Display the total number of scans for that role
  • Include print statements that clarify to the user the steps your program is taking or how it is solving the problem

Extensions

Complete at least ONE of the following:

  • Write to File: Save your analysis results to an output text file
  • Multiple Parameters: Modify your procedure to accept both role AND building as parameters, filtering by both criteria
  • Second Procedure: Create an additional procedure that performs different analysis (time-based filtering, specific badge lookup, building summary, etc.)
  • Statistical Summary: Count and display how many scans occurred in each building for the selected role
  • Time-Based Analysis: Add functionality to flag scans that occurred before or after specific times
  • Error Handling: Validate user input and provide helpful error messages for invalid entries

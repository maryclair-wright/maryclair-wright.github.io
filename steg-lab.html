Hide secret messages in images using binary encoding

What is Steganography?

Steganography is the practice of hiding secret information within ordinary files, images, or messages. Unlike encryption (which scrambles data so it looks like gibberish), steganography hides data in plain sight so no one even knows it exists.

In this tool, you'll hide text messages inside image files by modifying the least significant bits (LSB) of pixel color values. These tiny changes are invisible to the human eye, but they contain your secret message in binary code!

Step 5: Hide Message in Image

Steganography technique: We'll hide your message by modifying the least significant bit (LSB) of each pixel's color values.

Why doesn't this change the picture? Each pixel color is stored as a number from 0-255 (8 bits). Changing the last bit only changes the color value by 1. For example:
• Red = 10110110 (182) → 10110111 (183) — a difference of just 1
• This tiny change is imperceptible to the human eye!

We use one bit from each color value (Red, Green, or Blue) to store one bit of your message.

Question 2: Middle School Math Connection

In today's lab, you hid data in the LSB (last bit) of each RGB color value. Each pixel has 3 color values (Red, Green, Blue), so each pixel can store 3 bits of your message. This is a constant rate: 3 bits per pixel.

If you have a 200×200 pixel image, how many total pixels do you have? How many bits can you hide? Since each character needs 8 bits, how many characters can you hide? Explain how this shows proportional reasoning: as the number of pixels increases, the message capacity increases at a constant rate.

Question 3: Middle School Science Connection

You know that white light contains all colors of the rainbow, and that screens create colors by mixing red, green, and blue light. In today's lab, you worked with RGB color codes where each color goes from 0 to 255. Explain how mixing different amounts of red, green, and blue light creates the colors you saw on screen. What happens when all three values are 0? What about when all three are 255?

Question 4: High School Math Connection

In today's lab, you embedded a message into an image. Let's say you hid a 50-character message (which needs 50 × 8 = 400 bits) in a 100×100 pixel image.

Calculate the following:
• Total capacity: How many bits CAN the image hold? (Hint: 100×100 pixels × 3 bits per pixel)
• Embedding rate: What percentage of the available capacity did you use? (message bits ÷ total capacity × 100)

Then use statistical reasoning: If someone used 80% of an image's capacity versus only 2% of the capacity, which would be at higher risk of detection? Why? What does the embedding rate data tell us about the trade-off between message size and staying hidden?

Question 5: Life Science Connection

Many animals use camouflage or mimicry to hide from predators or prey, which increases their chances of survival and reproduction. In today's lab, you hid a message by making tiny changes that were invisible to the eye—the image looked the same but contained hidden information.

Explain how LSB steganography is similar to animal camouflage. How does "hiding in plain sight" with minimal changes help both the hidden message and the camouflaged animal avoid detection? Give a specific example of an animal behavior or specialized structure (like a stick insect, peppered moth, or octopus changing color) and connect it to what you did in the lab today.

Question 6: Physical Science Connection

In electronic devices, all data is stored and transmitted as electrical states—typically representing 1s and 0s. In today's lab, you worked with binary data (bits) that represent text characters.

Trace the path of one message bit through the system: Start with a bit from your character's binary code (for example, the first "1" in 00100001). Explain how that bit gets stored in the LSB of a pixel's color value. Then explain how that tiny electrical state change (1 bit difference) in the computer's memory still successfully carries your message when someone decodes the image.

How does this demonstrate that digital communication technologies rely on binary encoding in electronic systems?

Mars Rover Mission Control: Boolean Procedures

Overview

In this activity, you'll build procedures to check various systems on a Mars rover. You'll start simple and gradually add complexity, learning how to use boolean variables to make decisions about rover operations.

Level 1: Single Parameter Check

Whole Class Example

Scenario: The rover's communication system has AVAILABILITY - it can send data if signal strength is at least 50.

Write a procedure named checkSignal that accepts one parameter: signalStrength (integer). The procedure should print whether communication is available. Do NOT return a value. Do NOT use global variables.

Problems

Problem 1: Battery Check

Scenario: The rover's battery is available if charge level is greater than 20.

Write a procedure named checkBattery that accepts one parameter: chargeLevel (integer). The procedure should print whether the battery is available. Do NOT return a value. Do NOT use global variables.

Level 2: Two Parameters with AND (Return Status Message)

Problems

Problem 2: Data Integrity

Scenario: The rover has DATA INTEGRITY when transmitting - data is reliable if signal strength is not equal to 0 AND no interference detected.

Write a procedure named checkDataIntegrity that accepts two parameters: signalStrength (integer) and hasInterference (boolean). The procedure should return "SECURE: Data integrity maintained" if data is reliable, otherwise returns "WARNING: Data integrity compromised".

Example of how to call this procedure:

print(checkDataIntegrity(75, False))
print(checkDataIntegrity(40, True))

Problem 3: Rover Operational Status

Scenario: The rover is operational if battery is at least 30 AND solar panels are deployed.

Write a procedure named checkOperational that accepts two parameters: batteryLevel (integer) and panelsDeployed (boolean). The procedure should return "OPERATIONAL: All systems go" if operational, otherwise "OFFLINE: Systems not ready".

Level 2.5: Single Parameter with Multiple Conditions (if/elif/else)

Problems

Problem 3.5: Battery Status Report

Scenario: The rover needs to report battery status with different messages based on charge level:

  • If battery is at least 50, status is "HEALTHY"
  • If battery is at least 20, status is "LOW"
  • Otherwise, status is "CRITICAL"

Write a procedure named checkBatteryStatus that accepts one parameter: batteryLevel (integer). The procedure should return the appropriate status string.

Problem 3.6: Signal Quality Assessment

Scenario: The rover needs to assess signal quality with different messages:

  • If signal strength is greater than 60, quality is "STRONG"
  • If signal strength is at least 30, quality is "WEAK"
  • Otherwise, quality is "NO SIGNAL"

Write a procedure named assessSignalQuality that accepts one parameter: signalStrength (integer). The procedure should return the appropriate quality string.

Level 3: Two Parameters with OR

Problems

Problem 4: Power Availability Through Redundancy

Scenario: The rover maintains AVAILABILITY through redundancy - power is available if battery level is at least 29 OR solar panels are generating power.

Write a procedure named checkPowerAvailability that accepts two parameters: batteryLevel (integer) and solarGenerating (boolean). The procedure should print whether power is available. Do NOT return a value.

Problem 5: Communication Redundancy

Scenario: Communication is available if main antenna is working OR backup antenna is working.

Write a procedure named checkCommunication that accepts two parameters: mainAntenna (boolean) and backupAntenna (boolean). The procedure should print whether communication is available. Do NOT return a value.

Level 4: Adding NOT (Return Numbers)

Important: When storing the result in a variable, make sure your variable name is different from both the procedure name and the parameter names. This helps avoid confusion in your code.

Problems

Problem 6: Data Processing Check

Scenario: We need to verify DATA INTEGRITY - data should be processed if it has NOT been corrupted AND the error count is not equal to 0.

Write a procedure named checkDataProcessing that accepts two parameters: isCorrupted (boolean) and errorCount (integer). The procedure should return the integer 1 if data can be processed, otherwise returns 0.

Example of how to call this procedure and store the result:

processingStatus = checkDataProcessing(False, 0)
print("Processing status: " + str(processingStatus))

Notice: The variable name processingStatus is different from the procedure name checkDataProcessing and the parameter names isCorrupted and errorCount.

Problem 7: Emergency Mode

Scenario: Emergency mode activates if battery is less than 20 AND NOT currently charging.

Write a procedure named checkEmergencyMode that accepts two parameters: batteryLevel (float) and isCharging (boolean). The procedure should return the battery level as a float if emergency mode should activate, otherwise returns 0.0. Store the result in a variable with a different name than the procedure or parameters.

Level 5: Adding RETURN

Problems

Problem 8: Secure Transmission (Confidentiality)

Scenario: CONFIDENTIALITY check - we can transmit sensitive science data if encryption is enabled AND signal strength is at least 60.

Write a procedure named canTransmitSecure that accepts two parameters: encryptionOn (boolean) and signalStrength (integer). The procedure should return True if secure transmission is possible, otherwise returns False.

Problem 8.5: Transmission Priority Level

Scenario: Determine transmission priority based on encryption and signal strength:

  • If encryption is enabled AND signal strength is at least 70, return "HIGH PRIORITY"
  • If encryption is enabled AND signal strength is at least 40, return "MEDIUM PRIORITY"
  • Otherwise, return "LOW PRIORITY"

Write a procedure named getTransmissionPriority that accepts two parameters: encryptionOn (boolean) and signalStrength (integer). The procedure should return the appropriate priority string.

Level 6: Complex Logic (CIA Triad)

Problems

Problem 9: Mission Readiness

Scenario: Complete mission readiness check covering the CIA Triad:

  • Confidentiality: Encryption enabled
  • Integrity: Sensors calibrated
  • Availability: Battery is greater than 40 OR solar panels working

Write a procedure named isMissionReady that accepts four parameters: encryptionOn (boolean), sensorsCalibrated (boolean), batteryLevel (integer), and solarWorking (boolean). The procedure should return True if ALL three security properties are satisfied, otherwise returns False.

Extension Challenge: Rover Mission Status System

Problem 10: Comprehensive Mission Status

Scenario: Create a comprehensive mission status system that evaluates the rover's overall readiness based on multiple factors. The system should assess battery level, communication status, and scientific instruments.

Write a procedure named evaluateMissionStatus that accepts five parameters:

  • batteryLevel (integer)
  • commSystemOnline (boolean)
  • instrumentsCalibrated (boolean)
  • solarPanelsDeployed (boolean)
  • temperatureCelsius (integer)

The procedure should return one of the following mission status strings based on these conditions (check in this order):

  • If battery is at least 80 AND communication system is online AND instruments are calibrated AND temperature is greater than -50, return "MISSION READY: All systems optimal"
  • If battery is at least 50 AND (communication system is online OR solar panels deployed) AND temperature is greater than -80, return "MISSION READY: Systems functional"
  • If battery is at least 30 AND communication system is online, return "LIMITED OPERATIONS: Minimal systems only"
  • If battery is at least 15, return "SURVIVAL MODE: Awaiting power restoration"
  • Otherwise, return "CRITICAL: Immediate intervention required"

Hint: This problem requires you to combine boolean logic (AND/OR/NOT) with if/elif/else statements. Make sure to check conditions from most restrictive to least restrictive.

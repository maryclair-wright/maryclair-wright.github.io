Red Light Camera Command System

Traffic Engineering & Safety Management

Activity Instructions

  1. Create a procedure called registerCameraIntersection()
  2. At the start of your procedure, print: "---Red Light Camera Intersection Monitoring Station---"
  3. Create a try/except block to catch ValueError
  4. Inside the try block, collect user input:
    • Prompt for camera ID number and convert it to an integer
    • Prompt for intersection name
    • Why inside try? The int() conversion can raise a ValueError if the user enters invalid input (like text instead of a number). By placing the input collection inside the try block, we can catch this error immediately when it occurs.
  5. After collecting input, use an if/else statement to check:
    • If camera ID > 1000 AND "Main" is in the intersection name:
      • Set priorityLevel = "HIGH"
      • Isolate the first half of the value stored in intersectionName
      • Print a formatted string that includes: priority level, then camera ID, then the first half of intersection name
    • Otherwise → set priorityLevel = "STANDARD" and print appropriate output
  6. In the except ValueError block:
    • Display an error message explaining the invalid input
    • Optionally, ask the user to re-enter the information or set priorityLevel = "ERROR"
  7. Print or return the priorityLevel from your procedure
  8. Call your procedure and store the result in a variable (if you chose to return the value)

Example Output

Example 1 - HIGH Priority (No Exception):

---Red Light Camera Intersection Monitoring Station---
Enter camera ID: 1250
Enter intersection name: Main-5th
HIGH 1250 Main

Example 2 - ValueError Exception:

---Red Light Camera Intersection Monitoring Station---
Enter camera ID: abc
Error: Invalid camera ID. Please enter a number.

Why ValueError is the Right Choice

  • When we use int(input()), we're asking Python to convert user input (always a string) into an integer
  • If the user types something like "abc" or "12.5", Python receives the correct data type (string), but the value doesn't meet the requirements for conversion to an integer
  • The type is correct (string), but the value is inappropriate for the operation (converting to int)
  • This is exactly what ValueError is designed to catch
  • Contrast: TypeError occurs with incompatible types like "5" + 3; ZeroDivisionError occurs when dividing by zero

Extension Challenges

  • Camera ID Validation Range: Add validation to ensure the camera ID is between 100 and 9999. If outside this range, set priorityLevel to "INVALID" with an appropriate message.
  • Data Logging String Builder: Create a generateLogEntry() procedure that takes camera ID, intersection name, and priority level as parameters. Ask the user for the current hour (0-23) and return a formatted string like: "[14:00] Camera #1250 at Main-5th registered with HIGH priority"

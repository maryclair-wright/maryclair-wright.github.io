Finding and Fixing Logic Errors in Conditional Statements

Lab Objectives

By the end of this lab, you will be able to:

  • Understand that elif statements are evaluated in sequential order from top to bottom
  • Recognize that once a condition evaluates to True, all subsequent conditions are skipped
  • Debug code by using systematic testing strategies
  • Apply logical reasoning to determine proper condition ordering
W

Understanding Logic Errors

College Board Definition: A logic error is a mistake in an algorithm or program that causes it to behave incorrectly or unexpectedly. The program runs without crashing, but produces incorrect results.

Look at the algorithm below:

ans = 9 if (ans > 3): print(3) elif (ans > 5): print(5) else: print("else")
Important: The code below has a logic error! Don't assume it works correctly. Your job is to find the bug through testing and analysis.

Sample ASCTE Quiz Grade Scale

  • Mastery: Score ≥ 87
  • Proficiency: Score ≥ 72
  • Emerging: Score > 54
  • Beginning: Score ≥ 40
  • Incomplete: Score < 40

Read the Buggy Code

Carefully read through the code below. This function is supposed to classify grades according to the ASCTE grading scale, but it has a logic error.

def classifyGrade(score): if score >= 40: return "Beginning" elif score > 54: return "Emerging" elif score >= 72: return "Proficiency" elif score >= 87: return "Mastery" else: return "Incomplete"
2

Code Tracing

Trace through the code with the following two example scores:

Example 1: classifyGrade(95)
Example 2: classifyGrade(50)
3

Identify the Pattern

Based on your code tracing, identify what is causing the logic error.

Key Concept: When Python encounters an if-elif-else structure, it checks each condition in order from top to bottom. As soon as it finds a condition that is True, it executes that block and skips ALL remaining elif and else blocks.
4

Determine the Solution

Think about how to fix the code.

General Rule: When using if-elif-else for ranges, always check from most specific to least specific. For grades, this usually means checking highest values first, then working down to lowest values.

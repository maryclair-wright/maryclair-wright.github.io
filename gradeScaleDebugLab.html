Lab Objectives

W

Understanding Logic Errors

College Board Definition: A logic error is a mistake in an algorithm or program that causes it to behave incorrectly or unexpectedly. The program runs without crashing, but produces incorrect results.

Look at the algorithm below:

ans = 9 if (ans > 3): print(3) elif (ans > 5): print(5) else: print("else")

Identify the Pattern

Based on your code tracing, identify what is causing the logic error.

Key Concept: When Python encounters an if-elif-else structure, it checks each condition in order from top to bottom. As soon as it finds a condition that is True, it executes that block and skips ALL remaining elif and else blocks.

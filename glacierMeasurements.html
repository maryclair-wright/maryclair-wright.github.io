Glacier Ice Analysis

Practice Day - Build Your Programming Skills

Scenario: You're working with an Arctic research team that collects ice thickness measurements from glaciers. Your job is to create a program that processes these measurements and provides useful information to the research team.

Challenge: As you build your program, create at least one procedure to organize your code and make it reusable!

Core Challenge

Level 1: Single Sample Analysis (Start Here!)

Your program should:

  1. Ask the user for a single ice thickness measurement (in meters)
  2. Classify the measurement:
    • Less than 5 meters = "Critical"
    • Between 5 and 15 meters (inclusive) = "At Risk"
    • Greater than 15 meters = "Stable"
  3. Calculate the ice volume for that measurement
    • Each sample represents a 10m × 10m area
    • Volume = thickness × 10 × 10
  4. Display the classification and volume
Example Output: 
Enter ice thickness in meters: 8.5
Classification: At Risk
Volume: 850 cubic meters
Test your code with different values before moving on!

Level 2: Count Critical Samples (Next Step!)

Your program should:

  1. Ask the user how many samples they collected
  2. Use a loop to get each measurement
  3. Count how many samples are Critical (less than 5 meters)
  4. Display the count
Example Output: 
How many samples did you collect? 5
Enter measurement 1: 12.3
Enter measurement 2: 4.2
Enter measurement 3: 18.7
Enter measurement 4: 6.8
Enter measurement 5: 3.1

Critical samples found: 2

Extensions (If You Finish Early)

Choose any of these to add to your Level 2 program:

Extension A: Count All Categories

Count and display Critical, At Risk, AND Stable samples.

Extension B: Total Volume

Calculate and display the total ice volume across all samples.

Extension C: Average Thickness

Calculate and display the average ice thickness across all samples.

Extension D: Percentage Critical

Calculate what percentage of samples are Critical.
Example: "Critical samples: 2 out of 5 (40%)"

Extension E: Thickest and Thinnest

Track and display which sample was the thickest and which was the thinnest.
Example: "Thickest sample: 18.7 meters (sample 3)"

Extension F: Safety Alert

If more than 50% of samples are Critical, display a special warning message.

Extension G: Store and Review

Store all measurements in a list, then allow the user to search by sample number to see detailed information.

Tips for Success

  • Start small: Get Level 1 completely working before moving to Level 2
  • Test frequently: Run your program after each new feature
  • Use meaningful variable names: iceThickness is better than x
  • Remember camelCase: First word lowercase, capitalize each additional word
  • Ask for help: Stuck? Ask a classmate, BOOST tutor, or me!

Credit Card Validator Lab

Scenario

You're building a credit card validator for an online payment system. Your job is to check if credit card numbers are formatted correctly before they're processed.

Lab Requirements

  • You must define at least one procedure (function) in Part 2
  • You are encouraged to define additional procedures throughout the lab (Parts 7 and 8 are good candidates)
  • Use of global variables is optional - you may pass values as parameters instead

Part 1: Setup & User Input

Write code that asks the user to enter a credit card number and stores it in a variable called cardNumber.

Test with: 4532 1234 5678 9012 (with spaces)

Part 2: Remove Spaces (Method Practice)

Credit cards are sometimes entered with spaces like: 4532 1234 5678 9012

Define a function called removeSpaces(cardNumber) that:

  • Takes a card number as a parameter
  • Uses .replace(" ", "") to replace all spaces with empty strings
  • Remember: "" means an empty string (nothing between the quotes)
  • In this context: Replacing spaces with "" removes the spaces entirely
  • Example: "4532 1234" becomes "45321234"
  • Returns the cleaned card number as a new string (use the return keyword)
Important: After defining this function, call it and update the value stored in cardNumber:
cardNumber = removeSpaces(cardNumber)
This stores the returned value (without spaces) back into the cardNumber variable.
Test with: "4532 1234 5678 9012" should return "4532123456789012"

Part 3: Check Length

Valid credit cards have exactly 16 digits.

Before checking the length, print a message to the user like "---------- Checking Length ----------" to show what your program is doing.

Write an if/else statement that:

  • Checks if len(cardNumber) equals 16
  • Prints "Valid length" or "Invalid length"
Test with:
"4532123456789012" should print Valid length
"453212345678" should print Invalid length

Part 4: Check Card Type

Visa cards start with the digit 4.

Print a message to the user like "---------- Checking Card Type ----------" before performing the check.

Write an if/else statement that:

  • Evaluates to True if the first digit of the card number is "4"
  • Prints "Visa card" when the condition is true
  • Prints "Unknown card type" when the condition is false
Important: Use bracket notation (also called substring notation) to access the first character, not the .index() method. The .index() method is used to find where a character is located, not to get a character at a specific position.
Test with:
"4532123456789012" should print Visa card
"3532123456789012" should print Unknown card type

Part 5: Check Security Digit (Mod Math)

For this system, the last digit must be evenly divisible by 3.

Print a message to the user like "---------- Checking Security Digit ----------" before performing the check.

Write code that checks if the last digit is divisible by 3 and prints "Valid security digit" or "Invalid security digit".

Test with:
"4532123456789012" with last digit 2 should print Invalid security digit
"4532123456789009" with last digit 9 should print Valid security digit

Part 6: Check All Digits

Credit cards should only contain numbers (after spaces are removed).

Print a message to the user like "---------- Checking for Non-Digit Characters ----------" before performing the check.

Python has a helpful string method called .isdigit() that returns True if all characters in a string are digits, and False otherwise.

if cardNumber.isdigit():
    # your code here

Write code that uses .isdigit() to check if the entire card number contains only digits, and prints "All digits" or "Contains non-digits".

Test with:
"4532123456789012" should print All digits
"4532-1234-5678-9012" should print Contains non-digits

Part 7: Format for Display

For security, only show the last 4 digits when displaying: **** **** **** 9012

Define a function called formatCard(cardNumber) that:

  • Uses slicing to get the last 4 digits
  • Returns a formatted string that shows asterisks for the first 12 digits and the actual last 4 digits
Test with: "4532123456789012" should return "**** **** **** 9012"

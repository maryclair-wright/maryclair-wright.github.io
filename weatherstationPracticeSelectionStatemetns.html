Problem 6.2: Temperature Conversion and Classification Procedure

Write a procedure called analyzeTemperature that takes two parameters: tempCelsius (number) and locationCode (string). The procedure should calculate the temperature in Fahrenheit using the formula: (tempCelsius * 9/5) + 32. Then extract the first two characters of the locationCode using substring notation. Print the location prefix, both temperatures, and classify as "Hot" if Fahrenheit is above 86°F OR Celsius is above 30°C, otherwise print "Moderate".

Test Case 1:
analyzeTemperature(32, "NYC001")
Expected Output:
Location: NY
Temperature: 32°C / 89.6°F
Classification: Hot
Test Case 2:
analyzeTemperature(20, "LAX045")
Expected Output:
Location: LA
Temperature: 20°C / 68.0°F
Classification: Moderate
Sample Answer:
Note: This is ONE possible correct answer. Your code may look different and still be completely correct! There are multiple ways to solve this problem.
# Python Solution def analyzeTemperature(tempCelsius, locationCode): tempFahrenheit = (tempCelsius * 9 / 5) + 32 locationPrefix = locationCode[0:2] print("Location: " + locationPrefix) print("Temperature: " + str(tempCelsius) + "°C / " + str(tempFahrenheit) + "°F") if tempFahrenheit > 86 or tempCelsius > 30: print("Classification: Hot") else: print("Classification: Moderate") # Test the procedure analyzeTemperature(32, "NYC001") analyzeTemperature(20, "LAX045")

Key Takeaways

  • Comparison Operators: > (greater than), < (less than), >= (greater than or equal), <= (less than or equal), == (equal to), != (not equal to)
  • Logical Operators: AND (both conditions true), OR (at least one condition true), NOT (reverses the boolean value)
  • Code Style: Use camelCase for variables, avoid negative indexing, use clear and descriptive variable names
  • Multiple Solutions: Remember that there are often many correct ways to solve a problem - your approach may differ from the sample answers!

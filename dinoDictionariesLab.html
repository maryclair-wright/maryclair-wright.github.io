Dinosaur List Project

Getting Started

Step 1: Create Your Dinosaur Name List

Using your plastic dinosaur as inspiration, create a Python list of at least five dinosaur names.

Step 2: Write a Function to Find the Longest Name

Your task is to write a function called findLongestName() that takes a list of dinosaur names and returns the longest name in the list.

Think about:

  • How will you know which name is longest? What built-in function helps measure strings?
  • What information do you need to store while looping through the list?
  • What should your starting comparison value be?

Step 3: Test Your Function

  • Run your function and print the result to see if it correctly identifies the longest dinosaur name.
  • Try adding more dinosaur names to see how the function handles it.

Part 1: Create Dinosaur Dictionaries

Create two dinosaur dictionaries with at least three key-value pairs each. Think about characteristics like speed, diet, size, time period, or habitat.

dinoOne = {"name": "Tyrannosaurus", "diet": "carnivore", "speed": 25}
dinoTwo = {"name": "Triceratops", "diet": "herbivore", "speed": 15}

Part 2: Expand Your Dinos

  • Add at least two new key-value pairs to each of your existing dinosaurs.
  • Introduce a third dinosaur, ensuring it has a set of key-value pairs similar to the others.

Part 3: Modify Dino Data

  • Write code to change one value for each dinosaur in your collection.

Part 4: Cleanup Time

  • Remove one key-value pair from each dinosaur's data.

Part 5: Dino Comparisons

  • Write an if statement that compares the dinosaurs in some meaningful way.
  • Use a for loop to help with the comparison across your dino collection.

Part 6: Dino List of Dictionaries

Store all your dinosaur dictionaries inside a single list:

dinoList = [dinoOne, dinoTwo, dinoThree]

Write code that loops through the list and prints one specific value (such as the dinosaur's name, speed, or another key) from each dictionary.

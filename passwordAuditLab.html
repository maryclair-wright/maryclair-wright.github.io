Password Audit System

Scenario

Your company's IT security team has identified a list of employee passwords that need to be audited for compliance with the organization's security policy. Passwords must be at least 8 characters long to meet minimum security requirements.

Your task is to write a Python program that will strengthen weak passwords and generate an audit report. This connects to the Confidentiality principle of the CIA triad - stronger passwords make it harder for unauthorized users to gain access and view sensitive information.

The audit report will be saved to a file called passwords.txt so the security team can review the changes and determine if additional security measures are needed.

Level 1: Create the Password List

First, you need to create a list of passwords to audit. Your list must contain at least 15 passwords. Make sure to include a mix of passwords - some that are 8 or more characters (strong) and some that are fewer than 8 characters (weak).

Use this password list in your program:

passwordList = ["secure123", "pass", "myP@ssw0rd", "abc", "welcome2024", "test", "admin", "P@ssw0rd2024", "qwerty", "letmein", "12345", "cyberSecurity!", "temp", "CompanyPolicy1", "xyz"]

This list contains 15 passwords with a mix of strong passwords (8+ characters) and weak passwords (fewer than 8 characters). Copy and paste this list directly into your program.

Level 2: Count Weak Passwords

Before you modify anything, you need to count how many passwords don't meet the security requirements.

Your task: Write a for loop that traverses your password list and counts how many passwords have fewer than 8 characters.

Hints:

  • Create a counter variable before your loop (set it to 0)
  • Use len(password) to check the length of each password
  • Use an if statement inside your loop to check if the password is too short
  • Increment your counter when you find a weak password

Test your code with a print statement to verify your count is correct.

Level 3: Write the Audit Report to a File

Now that you've analyzed the passwords, you need to create an audit report file to document your findings. This file will be called passwords.txt and will contain the statistics and password list for the security team to review.

File Writing Basics:

auditFile = open("passwords.txt", "x")
auditFile.write("Your text here")
auditFile.close()

Your task: After your password counting loop, write code that:

  1. Opens a file called passwords.txt
  2. Writes this exact sentence: "Password audit complete. Found X weak passwords." (replace X with your actual count)
  3. Writes the entire password list as one line with spaces between passwords
  4. Closes the file
Important File Management: The "x" mode creates a new file. If passwords.txt already exists, your program will crash. Before each test run, manually delete the passwords.txt file from your file explorer. This ensures you're starting fresh each time.

Adding Spaces: To add a space after each password when writing, use password + " "

Run your code and check that passwords.txt was created with the correct content.

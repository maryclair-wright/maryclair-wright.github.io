Password Strength – Reference

Reference Models

  • Total combinations = (character set size)password length
  • Time to crack = total combinations ÷ attempts per second

Attack Scenarios

  • Online, rate limited: 1,000 attempts per second
  • Offline, no limits: 100,000,000,000 attempts per second

Character Sets

  • Lowercase only: size 26
  • Lowercase and uppercase: size 52
  • Lowercase, uppercase, numbers: size 62
  • Lowercase, uppercase, numbers, symbols: size 94

Using Iteration to Draw Snowflakes in Python

Objective: Use nested iteration to create geometric patterns while exploring how loops can generate complex visual designs from simple repeated instructions.

Time Required: 35-45 minutes

What You'll Learn:

  • How to use the turtle graphics library
  • Combining loops with drawing commands
  • Understanding how nested iteration creates complex patterns
  • The mathematical relationship between loop iterations and angles

Step 1: Import the Turtle Library

The turtle library is a pre-installed Python library that enables users to create pictures and shapes by providing them with a virtual canvas. Think of it like controlling a robot that leaves a trail wherever it moves.

import turtle

Run this line to make the turtle library available in your program.

Step 2: Create Your Turtle Object

Make a turtle object to do your drawing. You can name it whatever you like. This example uses elsa because snowflakes, but choose any name that makes sense to you.

elsa = turtle.Turtle()

Important: When writing code, you must match the spelling, punctuation, and case exactly. This has to be turtle.Turtle() or it won't create a turtle. Notice the capital T in Turtle().

Understanding the Coordinate Plane: Your turtle starts at position (0, 0), which is the center of the screen. The turtle canvas uses a coordinate plane where:

  • Positive x values are to the right, negative x values are to the left
  • Positive y values are up, negative y values are down
  • The turtle starts facing to the right (east)

Click here to view the coordinate plane image if it doesn't display above.

If you want to move your turtle to a different starting location to test the coordinate system, you can use:

elsa.goto(100, 50)  # Moves turtle to position (100, 50)

You can also adjust the drawing speed. Try adding this line:

elsa.speed(5)

Speed can be set from 1 (slowest) to 10 (fast), or 0 (instant).

Step 4: Add Some Iteration

Instead of writing the same commands over and over, use a loop to repeat your pattern. Start by creating a simple branch that repeats.

for i in range(4):
    elsa.forward(50)
    elsa.right(90)
Question: What shape does this code draw? Why does using 90 degrees with 4 repetitions create this shape?

Now try making a branch pattern:

for i in range(3):
    elsa.forward(30)
    elsa.backward(30)
    elsa.right(45)

Step 6: Attempt Nested Iteration

Now for the challenge: how can you turn your single branch into a full snowflake that repeats all the way around? You will need to use nested iteration, which means putting one loop inside another loop.

Your Task: Try to create code that draws your branch pattern multiple times in a circle. Think about:
  • How many times should the outer loop repeat to make a complete snowflake?
  • How many degrees should you turn after each branch?
  • What is the relationship between the number of branches and the angle of each turn?

Attempt this on your own first. After you have tried, you can look at this example structure of nested iteration:

for i in range(10):
    # Your inner loop and drawing commands go here
    elsa.right(36)
Mathematical Connection: Notice that if the outer loop repeats 10 times and turns 36 degrees each time, we turn 360 degrees total, which is a complete circle. This is why the pattern repeats around the center point.

Think About It: What would happen if you used 8 repetitions instead of 10? What angle would you need for each turn?

Run your code now and see what happens on the screen.

Step 7: Enhance Your Snowflake Design

Make your snowflake more complex by adding variation to the inner loop. Here is an example structure that creates a more intricate branch:

for j in range(4):
    elsa.forward(20)
    elsa.forward(20)
    elsa.backward(40)
    elsa.right(90)
Notice: This creates 4 small branches within each main branch. Try experimenting with different numbers and angles to create your own unique pattern.

Run your code now and see what happens on the screen.

Checkpoint: Do You Have a Working Snowflake?

At this point, you should have a complete snowflake drawing on your screen. Your code should have:

  • An outer loop that repeats multiple times
  • An inner loop inside the outer loop that draws the branch pattern
  • A turn command after the inner loop completes to rotate for the next branch

If your snowflake is not drawing correctly, compare your code to this working example:

import turtle

elsa = turtle.Turtle()
elsa.speed(8)
elsa.color("cyan")
elsa.pensize(2)

turtle.bgcolor("midnight blue")

for i in range(10):
    for j in range(3):
        elsa.forward(30)
        elsa.backward(30)
        elsa.right(45)
    elsa.right(36)

turtle.done()

Make sure your code has the same structure: an outer loop with an inner loop inside it, and the proper indentation for both loops.

Once you have a working snowflake, you're ready to move on to the challenge.

Advanced: Using Multiple Turtles

You can create multiple turtle objects to draw different snowflakes at the same time. Each turtle can have its own color, position, and pattern.

First, you need to move your turtle to a new location without drawing. Use these commands:

elsa.penup()        # Lift the pen so it doesn't draw
elsa.goto(-100, 50)  # Move to coordinates (-100, 50)
elsa.pendown()       # Put the pen down to start drawing again

To create a second turtle, simply make another turtle object with a different name:

# Second turtle - different snowflake
anna = turtle.Turtle()
anna.color("white")
anna.speed(8)
anna.penup()
anna.goto(150, 0)
anna.pendown()

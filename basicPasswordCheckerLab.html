Password Strength Checker - Coding Instructions

Objective: Create a simple password checker that uses a list, user input, selection, and iteration within a procedure to identify weak passwords.

What You'll Create: A console program that checks if a password starts with any weak characters from a predefined list.

Step 1: Create Your Weak Characters List

Create a list that stores weak characters. Weak characters are commonly used first characters that make passwords easy to guess.

weakCharacters = ['1', '2', '3', 'a', 'b', 'c']

Add at least two more characters to this list. Choose any keyboard characters you want. This will make your code unique.

Step 2: Add a Banner to Your Program

Add a banner that tells the user what the program does when it starts.

print("---- Basic Password Checker ----")

Run your code now. You should see the banner appear in the console.

Step 3: Get User Input

Ask the user to enter a password they want to test. Store their input in a variable.

Run your code now. The program should display your banner and then wait for you to type a password.

Step 5: Add Iteration and Selection to Your Procedure

Inside your procedure, use a loop to iterate through the weak characters list. For each character in the list, use selection to check if the password begins with that weak character.

Your procedure should return "WEAK" if the password starts with any weak character from the list, and return "PASS" if it does not.

Step 6: Call Your Procedure and Display Results

After your procedure definition, call the procedure and display the result to the user. Use the + operator in your print statement.

Run your code now. Test it with different passwords. Try passwords that start with '1' or 'a' (should show WEAK) and passwords that start with other characters (should show PASS).

Checkpoint: Does Your Program Have These?

Before moving on, make sure your program includes:

  • Output that displays the result

Testing Your Program

Test your program with these passwords to make sure it works correctly:

Cybersecurity Connection

This program relates to Confidentiality in the CIA triad. Weak passwords that start with common characters are easier for attackers to guess using brute force attacks. Real password checkers examine many factors including length, character variety, and common patterns.

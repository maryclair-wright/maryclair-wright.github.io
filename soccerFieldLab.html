Soccer Field Security Camera Coverage System

Python Turtle Cheat Sheet

Scenario

Your school is installing a new artificial turf soccer field divided into an 8-section grid for maintenance and monitoring purposes. The engineering team has already decided to install a security camera at section 3 because that's where the electrical hookup is located.

The camera can monitor sections within 2 spaces to the left and 2 spaces to the right of where it's mounted.

You're concerned about the Availability principle of the CIA triad - if sections of the field aren't monitored by cameras, footage from those areas won't be available. If an incident occurs in an uncovered section, you won't have access to the video evidence you need.

Before the school spends money on installation, you need to program a visual model of the engineering team's camera placement plan to see if it provides adequate coverage of the field sections.

Level 1: Draw One Field Section

Here's the code to get started. This imports the turtle library and creates your turtle named beckham:

import turtle

beckham = turtle.Turtle()
beckham.speed(8)

# Start position
beckham.penup()
beckham.goto(-240, 0)
beckham.pendown()

Now add code to draw ONE square that is 60 pixels on each side. You will need a loop that repeats 4 times (one for each side of the square).

Turtle Movement Reminders:

  • beckham.forward(distance) - moves the turtle forward
  • beckham.right(angle) - turns the turtle right
  • beckham.left(angle) - turns the turtle left

Run your code. You should see one field section.

Level 2: Make It a Grid Row

Now you need to draw 8 field sections in a row.

Think about this: Your code from Level 1 draws ONE section. How do you repeat that process 8 times?

You will need:

  • An outer loop that repeats 8 times
  • Your square-drawing code from Level 1 inside that outer loop
  • After drawing each square, move the turtle forward 60 pixels to the next position

Remember: Use beckham.penup() when you want to move without drawing a line, and beckham.pendown() when you're ready to draw again.

This is nested iteration - one loop inside another loop.

Run your code. You should see 8 connected field sections in a row.

Advanced Extension:

If you created a drawSquare() procedure in Level 1, you can call that procedure 8 times instead of repeating all the drawing code. This makes your code cleaner and easier to modify.

Level 4: Show Camera Coverage

The camera is at section 3 and can see 2 sections to the left and 2 sections to the right.

Think about this: Which section numbers will be covered by the camera? Refer back to your plan, sketch, or pseudocode.

To show which sections are covered, you need to modify your code. The covered sections should be filled with a color, and the uncovered sections should stay empty.

Understanding Fill Commands:

  • beckham.fillcolor("your_color") - sets what color will be used for filling
  • beckham.begin_fill() - tells the turtle to start filling the next shape it draws
  • beckham.end_fill() - tells the turtle to stop filling and complete the filled shape

One Way to Solve This:

Think about your row as TWO groups of sections:

  • Sections 1-5 are covered (need to be filled with color)
  • Sections 6-8 are not covered (should stay empty)

You can draw the covered sections first using one loop with filling, then draw the uncovered sections using another loop without filling.

Here's one possible structure (there are many ways to solve this):

beckham.fillcolor("your_color")

# Draw the 5 covered sections
for space in range(5):
    beckham.begin_fill()
    # your square-drawing code here (4 sides)
    beckham.end_fill()
    beckham.forward(60)

# Draw the 3 uncovered sections  
for space in range(3):
    # your square-drawing code here (4 sides, no fill commands)
    beckham.forward(60)

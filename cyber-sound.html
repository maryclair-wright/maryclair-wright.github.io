How this works

Some letters (like A = 000000) split into 3 identical bit pairs, so all 3 tones sound the same — that's correct, not a glitch, and you'll see a note next to those rows. This is the same basic idea behind real pay-by-sound systems: data becomes a sequence of tones, a microphone hears it, and software decodes it back. Real systems use tones outside human hearing; these are shifted into the audible range on purpose. The downloaded .wav file is the actual tone sequence for this message.
